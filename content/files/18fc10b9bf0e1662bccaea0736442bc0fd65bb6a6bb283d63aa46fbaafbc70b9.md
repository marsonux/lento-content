# 상단 메시지(스트릭 자극 문구) 템플릿

앱 홈 상단에 트랜지션으로 보여줄 문구 정의. 상태를 판정한 뒤 해당 항목의 헤드/서브를 렌더링한다.

## 표기 규칙

- `**굵게**` = 앱에서 **파란색 하이라이트**로 렌더링되는 구간 (헤드라인에서만 사용)
- `{변수}` = 런타임 값으로 치환
- 서브가 여러 줄이면 그중 하나를 랜덤 노출 (같은 문구가 연속으로 뜨지 않게)
- 판정 우선순위는 코드(`StreakMessageLibrary.candidates`)가 정한다 — 아래 '상태 판정 순서' 참고

## 변수

| 변수 | 의미 |
|---|---|
| `{streak}` | 현재 연속 일수 (지킨 날 기준 — 아래 설계) |
| `{best}` | 역대 최고 연속 (현재 연속 제외) |
| `{remaining}` | 오늘 남은 방울 수 |
| `{gap_days}` | 마지막 실행일로부터 지난 일수 |
| `{hours_left}` | 하루 경계(기본 04:00)까지 남은 시간(시) |
| `{diff_to_best}` | 최고 기록까지 남은 횟수 = `{best}` − `{streak}` |
| `{week_left}` | 이번 주 구슬까지 남은 방울 (주간 목표 % 기준) |
| `{week_percent}` | 이번 주 물이 찬 비율 (%) |
| `{week_goal}` | 주간 목표 (%) |
| `{goal_left}` | 오늘 목표까지 남은 개수 (= 올림(목표 % × 오늘 전체) − 모은 방울) |
| `{goal_total}` | 오늘 목표 개수 |
| `{goal_percent}` | 목표 % (하루·한 주 공통) |
| `{core_left}` `{core_total}` | 옛 이름 — `{goal_left}` `{goal_total}`과 같은 값 |
| `{drops}` | 오늘 모은 방울 수 |

## 설계 (9/28 하루 달성 → 10/11 전체 % 하나로)

- **지킨 날 = 오늘 물잔(전체 항목 완료율)이 목표 % 이상.** 단일 루틴도 항목 하나로 같이 센다. 목표 %는 첫 완주 뒤 고르고(기본 70) 설정에서 바꾸면 다음 주부터.
  습관 줄이기는 빠진다(자정 판정). 해야 할 게 없는 날(휴식·요일 아님)은 연속을 세지도 끊지도 않는다.
- **히어로 = 하루 메시지 ↔ 주간 메시지** 5초 교대. 하루 슬롯은 목표까지 남은 개수와 연속, 주간 슬롯은 구슬(같은 목표 %).
- 축하(마일스톤·신기록·다시 1일째·첫날)는 오늘을 지킨 뒤에. 그 전엔 "목표까지 n개"로 재촉한다.
- 지킨 뒤 더 하게 만드는 건 전부 완료(싹쓸이)와 이번 주 구슬.

## 상태 판정 순서 (10/10 손질)

**하루 슬롯**
1. 루틴 없음 → no_routine (빈 홈 히어로도 이 블록을 쓴다 — 서브는 첫 줄 고정)
2. 오늘 해야 할 루틴 없음 → today_off
3. 오늘 지킴 → 마일스톤 / 신기록 / 다시 1일째 / **첫날(first_kept)** / 전부 완료 / 지킴
4. 오늘 아직 → 최고 기록 근접 / 자리 비움·어제 놓침(아직 하나도 안 했을 때) / 자정 넘김 / **일부 진행** / 저녁 / 연속 구간별
   - 어제 놓침(gap_short)은 '지킨 날' 기준 — 어제 뭔가 했어도 못 지켰으면 뜬다 (앱의 약속: 두 번 연속으로는 빠지지 않는다)
   - 일부라도 한 날은 저녁에도 안 한 사람처럼 재촉하지 않고 남은 개수만 말한다 (자정 넘김은 예외)
   - streak_0은 끊긴 뒤에도 뜬다 (전엔 빈 상태)

**주간 슬롯** (이번 주 예정 방울이 0이면 주간 슬롯 없음)
1. 이번 주 구슬 오늘 수집 → marble_new
2. 이미 수집 → week_collected
3. 주 마지막 날(설정 '주 시작 요일' 기준) → 오늘 남은 방울로 닿으면 week_sunday / 못 닿으면 **week_wrap**
4. 구슬까지 1~3방울 (오늘 더 할 게 있을 때) → marble_near
5. 그 외 → week_progress

## 문구

### no_routine
- 조건: 등록된 루틴 0개
- 헤드: **첫 루틴**을 만들어볼까요?
- 서브:
  - 작게 시작할수록 오래 가요.
  - 쉬운 루틴에 꾸준히 하고 싶은 습관을 넣어봐요.
  - 루틴 없는 홈 화면은 좀 심심하거든요.

### milestone_7
- 조건: streak == 7, 오늘 지킴
- 헤드: **일주일 연속!** 첫 고비를 넘었어요
- 서브:
  - 일주일 이어간 사람은 생각보다 적어요. 진짜로요.

### milestone_14
- 조건: streak == 14, 오늘 지킴
- 헤드: **2주 연속**, 이제 안 하면 어색하죠?
- 서브:
  - 루틴이 슬슬 생활이 되고 있어요.

### milestone_30
- 조건: streak == 30, 오늘 지킴
- 헤드: **30일 연속!** 습관이 자리 잡았어요
- 서브:
  - 네? 한 달이요? 잠깐 박수 좀 치고 갈게요.

### milestone_100
- 조건: streak == 100, 오늘 지킴
- 헤드: **100일.**
- 서브:
  - 우리… 기념일이라도 만들까 봐요.

### best_new
- 조건: streak > best, 오늘 지킴, best >= 5
- 헤드: **역대 최장 연속 {streak}일!**
- 서브:
  - 과거의 나, 방금 추월당했어요.
  - 이건 캡처각.

### today_off
- 조건: 오늘 해야 할 루틴 없음 (휴식·요일 아님) — 연속은 그대로
- 헤드: 오늘은 **쉬는 날**이에요
- 서브:
  - 연속은 그대로 이어져요.
  - 쉬는 것도 루틴의 일부예요.

### marble_new
- 조건: [주간] 이번 주 구슬을 오늘 수집
- 헤드: **이번 주 구슬 획득!**
- 서브:
  - 구슬은 내 꾸준함의 결과예요.
  - 조금만 더 하면 반짝이는 구슬을 얻을 수 있어요.

### week_collected
- 조건: [주간] 이번 주 구슬 이미 수집
- 헤드: 이번 주 구슬을 **벌써 모았어요**
- 서브:
  - 좀 더 하면 구슬이 빛나기 시작해요
  - 이번 주 {week_percent}%까지 찼어요.

### week_sunday
- 조건: [주간] 주 마지막 날(설정 '주 시작 요일' 기준), 미수집, 오늘 남은 방울로 닿을 수 있을 때
- 헤드: 오늘이 **구슬 마지막 날**이에요
- 서브:
  - {week_left}방울이면 이번 주 구슬을 모아요.
  - 오늘 안에 {week_left}방울, 해볼 만하죠?

### week_wrap
- 조건: [주간] 주 마지막 날, 미수집, 오늘 남은 방울로는 못 닿을 때
- 헤드: 이번 주는 **{week_percent}%**로 마무리
- 서브:
  - 다음 주는 조금만 더 해볼까요?
  - 이번 주도 고생 많았어요!

### week_progress
- 조건: [주간] 기본
- 헤드: 이번 주 구슬 **{week_percent}%**
- 서브:
  - 목표 {week_goal}%까지 {week_left}방울 남았어요.
  - 방울을 모을수록 구슬이 차올라요.

### marble_near
- 조건: [주간] 이번 주 구슬 미수집, 남은 방울 1~3, 오늘 더 할 게 있을 때
- 헤드: 이번 주 구슬까지 **{week_left}방울**
- 서브:
  - 조금만 더 채우면 구슬 하나 수집!
  - 잠깐, 구슬이 곧 반짝일 것 같아요!

### best_near
- 조건: diff_to_best in 1..2, best >= 5, 오늘 아직
- 헤드: 최고 기록까지 **{diff_to_best}일**
- 서브:
  - 작은 습관의 힘, 알고 있죠?
  - {best}일의 벽, 이번엔 넘어볼까요?

### gap_long
- 조건: gap_days >= 14
- 헤드: **오랜만이에요!**
- 서브:
  - 보고 싶었다고 하면 믿어줄래요?
  - 루틴들이 {gap_days}일째 창가에서 기다렸대요.

### gap_mid
- 조건: gap_days in 3..13, 오늘 아직 하나도 안 함
- 헤드: **다시 시작할 준비** 됐나요?
- 서브:
  - 기록은 끊겨도 몸은 기억해요.
  - 목표까지 {goal_left}개면 다시 1일째예요.

### gap_short
- 조건: 어제 못 지킴('지킨 날' 기준 — 어제 뭔가 했어도, 지킨 이력이 있을 때만) 또는 gap_days == 2, 오늘 아직 하나도 안 함
- 헤드: 하루 쉬었으니 **오늘은 가볍게**
- 서브:
  - 목표까지 {goal_left}개, 그만큼만 해요.
  - 어제는 쉬는 날이었던 걸로 해요.
  - 두 번 연속만 안 빠지면 돼요.

### restart_1
- 조건: 끊긴 이력 있음, streak == 1, 오늘 지킴
- 헤드: **다시 1일째**, 돌아온 게 진짜예요
- 서브:
  - 이번 목표는 딱 2일까지.
  - 돌아오는 것도 실력이에요.

### today_done
- 조건: 오늘 전부 완료 (보너스)
- 헤드: **오늘 루틴 싹쓸이!**
- 서브:
  - 이건 좀 자랑해도 돼요.
  - 내일의 내가 오늘의 나를 보고 반할 예정.
  - 오늘은 푹 쉬어도 아무도 뭐라 안 해요.

### first_kept
- 조건: 오늘 지킴, streak == 1, 끊긴 이력 없음 (생애 첫 '지킨 날')
- 헤드: **첫날**을 성공적으로 해냈어요!
- 서브:
  - 첫 방울이 제일 어려운 법인데, 해냈어요.
  - 내일도 기대되는데요?

### today_kept
- 조건: 오늘 지킴 (예정 루틴 전부 핵심 개수만큼)
- 헤드: 오늘 몫 지켰어요, **연속 {streak}일**
- 서브:
  - 여유 있으면 평소처럼까지 가볼까요?
  - 오늘 {drops}방울 모였어요.
  - 조금 더 하면 조금 더 뿌듯하겠죠?

### core_partial
- 조건: 오늘 아직, 일부 진행 (방울 1개 이상)
- 헤드: 목표까지 **{goal_left}개** 남았어요
- 서브:
  - 오늘 {drops}방울 모였어요.
  - 여기까지 왔으면 거의 다 왔어요.

### today_midnight
- 조건: 오늘 아직, 자정 넘김(하루 경계 전), streak >= 3
- 헤드: **{hours_left}시간** 남았어요, {goal_left}개면 돼요
- 서브:
  - 연속 {streak}일, 놓치실 건가요?
  - 지금 멈추면 내일의 내가 좀 서운할지도.

### today_evening
- 조건: 오늘 아직, 18시 이후, streak >= 3
- 헤드: **연속 {streak}일**, 목표까지 {goal_left}개
- 서브:
  - 짧은 것부터 {goal_left}개만 해볼까요?
  - {goal_left}개만 하면 오늘도 연속이에요.

### streak_0
- 조건: streak == 0, 오늘 아직 (끊긴 뒤 어제가 쉬는 날이었던 경우도 여기)
- 헤드: 오늘 목표는 **{goal_left}개**예요
- 서브:
  - 바쁜 날엔 딱 그만큼이면 충분해요.
  - 첫 방울 떨어뜨려 볼까요?

### streak_1
- 조건: streak == 1 (어제 함), 오늘 아직
- 헤드: 어제 시작한 걸 **오늘도 이어볼까요?**
- 서브:
  - {goal_left}개면 연속 2일!
  - 어제의 나와 바통 터치!

### streak_2_3
- 조건: streak in 2..3, 오늘 아직
- 헤드: **연속 {streak}일째**, 킵고잉!
- 서브:
  - 목표만큼만 해도 연속 기록은 이어져요.

### streak_default
- 조건: streak >= 4, 오늘 아직
- 헤드: **연속 {streak}일** 진행 중
- 서브:
  - 꽤나 나와의 약속을 잘 지키는 사람이군요?
  - 구슬은 꾸준함의 결과예요.

## 컨텍스트 변주 (오늘 아직 + streak_* / today_evening / today_midnight 에서만, 서브 교체)

### ctx_weekend
- 조건: 토·일, streak >= 3
- 서브 교체: 주말에도 목표만 채우면 진정한 갓생.

### ctx_monday
- 조건: 주 첫날 (설정 '주 시작 요일' 기준)
- 서브 교체: 새 주, 새 구슬이 비어 있어요.
